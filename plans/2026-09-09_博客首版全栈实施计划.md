## 背景与目标

以当前已复制的全栈代码建立完全独立的个人博客。博客自行维护 Git、产品需求、部署和数据，不配置母版远端，不跟踪母版基线，不建立升级同步流程。用户已人工删除继承的全部实施计划；保留并更新计划治理文件，不恢复旧计划。

首版面向一位管理员和匿名读者，提供 Markdown 写作、文章发布与隐藏、软删除和恢复、分类标签、公开阅读及基础 SEO。

## 非目标

- 当前授权覆盖第二阶段后台写作实现、必要文档和轻量验证；第三阶段公开阅读页面保留规划。真实数据库迁移、专项测试和部署不在本轮执行。
- 不提交、推送、创建 Tag、发布镜像或部署，不修改母版目录或线上仓库。
- 不运行未被明确点名的 pytest、Vitest、production build、Playwright 或测试数据库迁移。
- 不开发读者注册、评论、留言、搜索、订阅、草稿、定时发布、历史版本或文章永久删除。

## 实施顺序与阶段验收

### 第一阶段：独立初始化

1. 保存现有文件原字节及 Git 恢复资料，核对用户删除范围。
2. 重建博客需求、计划登记、项目索引，建立 ADR 0016 并调整母版专用规则。
3. 隔离项目名、开发端口、Cookie、Redis、数据库模板和部署资源，解除母版发布配置。
4. 安装锁定依赖、生成契约和客户端、执行适用轻量检查，明确运行环境缺口。
5. 将旧 Git 元数据完整保存到仓库外，重新初始化 main，仅绑定博客 origin，不产生首次提交。
6. 回写结果和剩余环境操作，复读差异并清理本次临时检查资源。

### 第二阶段：后台写作

新增 posts、categories、tags、post_tags、post_assets。文章状态仅 public/hidden，deleted_at 独立，恢复后隐藏；slug 首次发布后固定且回收站继续占用；revision 只防并发覆盖。分类标签删除事务覆盖全部关联文章，包括回收站。图片引用由服务端解析并与文章保存同步，资产删除共享锁定规则。实现 Markdown 编辑、预览、图片插入、离开提醒和失败保留输入。

顺序：Backend → 导出根 OpenAPI → 生成 API Client → Admin 适配。完成标准是管理员能完成发布、编辑、隐藏、删除、恢复和分类标签管理。

#### 第二阶段落实方案

- 产品决定：隐藏和软删除不撤销已知图片直链；在用图片始终受到删除保护。本地统一 localhost:8000/3001/3000，生产容器内部端口维持现状，多项目宿主端口独立分配。
- 数据：新增 posts、categories、tags、post_tags、post_assets，保留现有迁移。文章包含标题、固定 slug、摘要、Markdown、可空封面资产、分类、标签、首次发布时间、更新时间、revision 和软删除字段。分类标签名称与 slug 各自唯一，文章标签最多 20 个，正文最多 200000 字符；均无草稿和历史正文。
- 后端：新增博客领域 Schema、规则、Router、Repository 与跨资产用例 Service。管理端提供文章分页、公开/隐藏、分类标签和北京时间日期筛选、详情、新建发布、保存、状态修改、单条/批量删除恢复；分类标签提供分页 CRUD、单条/批量删除影响预览和确认执行。
- 并发：文章及分类标签写入使用 revision；分类标签删除预览返回目标与关联摘要，提交重新核对。博客写事务先获取 PostgreSQL 事务级 advisory lock `(20260909, 1)` 串行化内容关联变更，锁等待上限 5 秒，再按用例锁文章与分类标签，最后按 UUID 锁新旧全部资产；资产删除持有相同资产行锁且不等待博客锁。解除分类标签关联时同步更新文章 revision，防止旧编辑内容恢复已删除关联。
- 图片：复用 article 上传场景；后端解析 Markdown 图片 token 和封面，校验本站受控 article 资产并记录引用。保存与资产删除并发时通过资产行锁和外键约束保护正文与封面。隐藏或软删除不解除引用。
- Markdown：把已锁定的 markdown-it-py 4.2.0 声明为直接运行依赖，关闭原始 HTML，限制链接协议与站内图片路径；增加 tzdata 2026.3 支持 Windows 时区转换。后台通过受保护、无持久化的预览 API 消费安全渲染结果；第三阶段复用同一后端渲染入口，不另造解析规则。官方安全依据为 [markdown-it-py 安全文档](https://github.com/executablebooks/markdown-it-py/blob/master/docs/security.md)。
- 后台：沿用 PageFrame、QueryState、ProTable、StandardConfirmModal、TanStack Query 和唯一 HTTP 管道。新增内容管理菜单、文章列表/回收站、独立编辑页、分类与标签页面。编辑器提供工具栏、图片上传与插入、封面、预览、未保存离开提醒和失败保留输入。
- 权限：新增 posts/categories/tags 精确端点权限和对应 Admin Access，复用管理员会话、CSRF、审计，不新增角色。新增权限通过已有显式同步命令初始化，不在应用启动时写库。
- 验证：新增安全渲染、生命周期、引用保护、删除确认、并发与页面关键交互测试源码；本轮不运行 pytest/Vitest/build/Playwright/真实数据库迁移。执行 Backend 静态检查、Admin/Web typecheck/lint、契约生成漂移、文档和边界门禁。

- 不复制母版真实环境文件、管理员、数据库或媒体；未配置博客凭据时不降低启动校验。

- 发布工作流在博客独立配置完成前阻断外部动作；不得自动使用原 CNB、镜像或生产主机。
- 已公开静态图片可通过已知直链访问；文章隐藏不提供图片保密。数据库回退不得删除已写入文章，新迁移采用受控恢复或前向修复，不提供静默丢数据的降级。
